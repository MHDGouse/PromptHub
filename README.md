# PromptHub

PromptHub is a prompt sharing website where you can discover, save, and share useful prompts with others.

If you have a prompt that you find helpful, you can publish it to PromptHub so other people can use it too. If you find a prompt that’s useful, you can copy it, share it, or send it directly to ChatGPT.

---

## Features

- **Sign in with Google** (create an account using your Google account)
- **Share prompts** (publish your best prompts for others)
- **Explore useful prompts** (find prompts shared by the community)
- **Use or share prompts easily**
- **Send to ChatGPT** (quickly copy/use a prompt in ChatGPT)

---

## How it works

1. **Sign in with Google**
2. **Create / add a prompt**
3. **Share it publicly** so others can find it
4. **Use prompts** you like (copy them or share them)
5. **Open in ChatGPT** to try a prompt instantly

---

## Use cases

- Collect and organize prompts you use often
- Share prompts with friends or a team
- Discover better prompts for:
  - writing
  - coding
  - learning
  - brainstorming
  - productivity
